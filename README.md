# BTT Ready Pro — Singapore Class 3A

Includes original topic-based flashcards, practice questions, timed mock exams, topic progress, spaced review, a mistake bank and a 7-day study plan.

## Run locally
Extract the ZIP, open a terminal in this folder, run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Install on a phone
Host all files on a static HTTPS website (e.g. GitHub Pages or Netlify). Open the site on your phone. On iPhone use Safari → Share → Add to Home Screen. On Android Chrome use Install app / Add to Home screen.

## Official resources

## Important
Cards and questions are original summaries, not official Traffic Police questions. Verify exact legal wording, signs, penalties and current rules in the official handbook. This app is independent and not affiliated with SPF or CDC. Study history is stored locally and does not sync across devices.
